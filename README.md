# Komok Translate

Простой статичный переводчик Komok на HTML, CSS и JavaScript. Интерфейс адаптирован под телефон, планшет и компьютер, использует предоставленную иконку Komok с радужной лисой-клубком и подключает открытый API MyMemory для перевода.

## Что есть

- Русский, английский и более 50 популярных европейских и азиатских языков.
- Автоопределение языка.
- Обмен языков местами.
- Кнопка копирования результата.
- История последних переводов в `localStorage`.
- Светлая и тёмная тема.
- Адаптивный интерфейс без фреймворков и сборки.

## Запуск в Windows

Откройте папку проекта в VS Code. В терминале PowerShell выполните:

```powershell
py -m http.server 3000
```

Затем откройте <http://localhost:3000>.

Если установлен VS Code Live Server, можно нажать правой кнопкой на `index.html` и выбрать **Open with Live Server**. Для настоящего перевода нужен доступ к интернету.

## Перевод

Сейчас используется публичный endpoint MyMemory:

```text
https://api.mymemory.translated.net/get
```

Это удобно для прототипа, но публичный API может иметь ограничения по частоте запросов. Перед коммерческим запуском рекомендуется перенести вызов на собственный серверный endpoint и подключить провайдера с понятными условиями использования.

## Публикация

Проект не требует `npm install`, сборщика или API-ключа. Его можно опубликовать как статический сайт через GitHub Pages, Vercel или Netlify. Для GitHub Pages в настройках репозитория выберите **Settings → Pages → Deploy from branch → main → /(root)**.

## Лицензии и атрибуция

Код проекта написан как самостоятельный vanilla HTML/CSS/JS. Визуальное направление ориентировано на сдержанную премиальную эстетику потребительских технологий, но не копирует элементы Apple. Иконка Komok предоставлена владельцем проекта.

Для будущей desktop-версии можно использовать MIT-шаблон [guasam/electron-react-app](https://github.com/guasam/electron-react-app), но текущая веб-версия специально оставлена без Electron, чтобы запускаться на Windows одной командой.
